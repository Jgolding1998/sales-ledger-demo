# Provenance and publication boundary

This directory is a newly authored, independent demonstration, not a filtered copy of an existing business dashboard. No previous business repositories, source tables, workbooks, generated reports, ERP configuration, datasets or history were read for its implementation. No real entity names were substituted or anonymized.

## Authored material

- `data.js`: fixed arithmetic generating invented SampleOrder/SampleAccount/Component identifiers, dates and amounts.
- `calc.js`: original pure JavaScript date, selection, aggregation, aging and CSV functions.
- `index.html`, `styles.css`, `app.js`: original UI led by the installed Claude Code under a narrowly scoped brief.
- `serve.js`, tests and documentation: original supporting code coordinated by Codex.

The UI uses native HTML controls, system fonts and original inline SVG shapes. There are no external assets, dependencies, vendored libraries, tracking snippets or remote data files. Public research links are references, not runtime dependencies; no third-party source was copied.

All product files are offered under the included MIT license, copyright Jgolding1998. Claude bridge requests, responses, logs, screenshots and machine-specific verification evidence belong outside this product directory and are not product content.

Publication must use only the reviewed allowlist and hashes in the separate handoff evidence. This document is a statement of the clean-room input boundary, not a guarantee that future edits or added data are safe to publish.
